# Podcast Raditya Dika

Website Podcast Raditya Dika — layout sliced from POTSHOW, purple-yellow-cream theme, real YouTube embeds of Raditya Dika's podcast.

## Cara menjalankan

Buka `index.html` di browser, atau deploy sebagai situs statis (misalnya di Vercel).

## Teknologi

- HTML, CSS, dan JavaScript dalam satu file statis (`index.html`)
- Embed YouTube podcast Raditya Dika
